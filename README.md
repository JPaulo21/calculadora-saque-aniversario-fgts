# API de Simulação do Saque-Aniversário do FGTS

Este projeto é uma API REST desenvolvida com Spring Boot que tem como objetivo simular o valor disponível para o saque-aniversário do FGTS.
A aplicação calcula quanto o trabalhador pode sacar com base no saldo total de suas contas vinculadas e nas faixas de saque definidas pela Caixa Econômica Federal.

## 🚀 Tecnologias Utilizadas

- Java 17+
- Spring Boot 3+
- Spring Web
- Spring Validation
- Spring Data JPA
- Banco de Dados: PostgreSQL
- Migrações de Banco: Flyway
- Documentação: springdoc-openapi (Swagger UI)
- Gerenciador de Build: Gradle
- Testes: JUnit 5 + Mockito
