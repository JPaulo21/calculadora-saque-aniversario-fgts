# API de Simulação do Saque-Aniversário do FGTS

Este projeto é uma API REST desenvolvida com Spring Boot que tem como objetivo simular o valor de recebimento do saque-aniversário do FGTS.
A aplicação calcula quanto o trabalhador pode sacar com base no saldo total de suas contas vinculadas e nas faixas de saque definidas pela Caixa Econômica Federal.
